# Support

## Getting help

| Channel            | Best for                       |
| ------------------ | ------------------------------ |
| GitHub Discussions | Questions, ideas, general help |
| GitHub Issues      | Bugs, feature requests         |
| Documentation      | Self-service (this site)       |

## Before asking

1. Read relevant docs page
2. Run lakreet-swarm doctor — include output
3. Run lakreet-swarm check — catches data errors
4. Search existing issues/discussions

## Bug reports

Include:

- lakreet-swarm doctor output
- Command that failed (exact)
- Error message (full)
- Template + data sample (minimal)
- OS, Node, EffectCraft versions

## Feature requests

Include:

- Use case (what problem does this solve?)
- Current workaround
- Priority for you

## Commercial support

For enterprise/consulting: support@lakreet.dev
