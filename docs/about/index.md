# About Lakreet

Lakreet is a collection of small, focused tools for open-source creative software.

## Mission

Build reliable, privacy-respecting automation tools that integrate with creative software — starting with EffectCraft.

## Projects

| Project                  | Description                                               | Status |
| ------------------------ | --------------------------------------------------------- | ------ |
| [lakreet-swarm](/swarm/) | Batch render videos from EffectCraft templates + CSV/JSON | v0.2.0 |
| More coming...           |                                                           |        |

## Unofficial statement

> **Independent project.** Lakreet is not affiliated with, sponsored by, or endorsed by the Storytold team, the EffectCraft project, or the ArtCraft project. We only call the public `effectcraft-cli` API.
